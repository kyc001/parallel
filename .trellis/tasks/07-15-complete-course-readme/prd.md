# 完善并行程序设计课程仓库 README

## Goal

将仓库根目录 README 从一句占位说明扩展为一份面向课程归档、代码阅读和项目展示的完整入口文档，清楚呈现本学期并行程序设计课程的作业构成、成绩、ANN 选题主线、各阶段实现、代表性实验结论、仓库目录和复现条件。

## Confirmed Facts

- 课程总评构成为：第一次作业 4.9/5，第二次作业 4.8/5，OT 协程技术调研 3.3/4，SIMD 15/15，多线程 18.5/20，MPI 15/15，GPU 9.7/10，期末研究报告 18.8/20，签到 6/6；合计 96/100。
- 前两次作业分别是并行体系结构调研和 CPU 架构编程，另有一次协程技术调研。
- 进阶选题为近似最近邻搜索（ANNS），使用 DEEP100K 数据集，底库 100000 个 96 维向量，主要以 Recall@K 和查询延迟衡量结果。
- ANN 实验沿 SIMD、Pthread/OpenMP、MPI、CUDA GPU 四个层级逐步展开，最终报告进一步研究预算自适应 IVF-PQ、OPQ/IVF-OPQ 和 GPU-CPU 异构协同。
- 仓库包含源代码、LaTeX/PDF 实验报告、运行脚本、性能数据、图表、profile 和汇编分析材料。
- 根目录 `README.md` 当前只有标题和一句英文占位说明。

## Requirements

- README 应以课程与仓库定位开篇，明确这是一份 2026 春季并行程序设计课程的代码和报告归档。
- 使用表格完整列出各项成绩、满分与得分率，并给出总分 96/100。
- 单独解释 ANN/ANNS 的问题背景、数据集、评价指标、离线建索引与在线查询边界。
- 按课程阶段说明每个目录实际完成的工作，不得只罗列目录名。
- 对 CPU 架构、SIMD、多线程、MPI、GPU 和期末报告给出仓库证据支持的代表性结果与性能结论。
- 明确性能数字依赖平台、参数、召回率和计时口径，避免把不同召回点写成严格排行榜。
- 提供清晰的仓库目录导航，区分个人实现、报告、数据、原始框架和参考模板。
- 提供构建/运行所需工具链与数据文件说明，但不承诺一个不存在的根目录统一构建命令。
- 链接关键报告、代码入口和子目录 README，所有相对链接应在 GitHub Markdown 中可用。
- 说明仓库用途为课程学习与实验复现；第三方 `hnswlib` 等内容保留其原始许可边界。
