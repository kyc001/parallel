Notes
- Recall is identical across platforms for the same algorithm parameters.
- Communication plus merge overhead is small compared with local search time
  in all recorded runs.
- The graph-index coverage includes assignment option A (IVF+HNSW), option B
  (block-HNSW), and option C (HNSW-on-HNSW).
- HNSW-on-HNSW reaches Recall@10 1.00000 with nprobe_blocks=16, but it is much
  slower on Kunpeng because it searches all local blocks after the top-level
  graph selection. This is useful report evidence for recall-latency trade-off.
- Keep direct and PBS logs because queue/node placement and shared cluster load
  can affect timing.
