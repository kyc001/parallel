# ann-gpu 提交与复现说明

本目录对应 GPU 编程作业，不再使用上一份 MPI 实验的 `mpic++`、`qsub_mpi.sh` 或 PBS 提交流程。

## 目录内容

- `main.cc`：保留原始 ANN 实验的薄入口框架，负责读数据、调用搜索函数、统计 Recall@10 和延迟。
- `gpu_ann_search.cuh`：header-only 聚合头，保持 `main.cc` 只包含一个 GPU 入口头文件。
- `gpu/`：CUDA 算法模块目录，拆分为通用工具、GEMM kernel、设备端 Top-k、GEMM batch 搜索和 IVF batch 搜索。
- `Makefile`：使用 `nvcc` 编译 `main.cc`。
- `img/`：AMD AUP HIP Lab1-Lab6 学习通过截图。
- `学习报告.md`：在线学习原始笔记。
- `report/main.tex`、`report/main.pdf`：最终实验报告源码和 PDF。

## 编译

本机已补齐 Windows CUDA 所需的 MSVC host compiler：Visual Studio Build Tools 2022 安装在 `C:\BuildTools`。`Makefile` 会在 Windows 下自动调用 `C:/BuildTools/VC/Auxiliary/Build/vcvars64.bat`，因此普通 PowerShell 中直接运行 `mingw32-make` 即可：

```bash
cd ann-gpu
mingw32-make
```

Linux 或其他已经配置好 host compiler 的 CUDA 环境也可以使用：

```bash
cd ann-gpu
make
```

也可以直接编译：

```powershell
cmd /C "call C:\BuildTools\VC\Auxiliary\Build\vcvars64.bat && nvcc -O3 -x cu main.cc -o build\main.exe"
```

如果换到一台没有 MSVC 的 Windows 机器，出现 `nvcc fatal : Cannot find compiler 'cl.exe' in PATH`，说明 CUDA 找不到 Visual Studio C++ host compiler。可安装 Build Tools：

```powershell
curl.exe -L -o vs_BuildTools.exe https://aka.ms/vs/17/release/vs_BuildTools.exe
$args = '--installPath C:\BuildTools --add Microsoft.VisualStudio.Workload.VCTools --includeRecommended --norestart --passive --wait'
Start-Process .\vs_BuildTools.exe -Wait -Verb RunAs -ArgumentList $args
```

安装完成后运行 `mingw32-make clean`、`mingw32-make` 验证。

## 运行

推荐运行：

```powershell
.\build\main.exe gemm 2000
.\build\main.exe ivf 2000 16 4
```

参数依次为：

- `mode`：`gemm` 或 `ivf`，省略时默认为 `gemm`。
- `query_n`：搜索的 query 数，默认 2000。
- `nlist`：IVF 簇数，仅 `ivf` 模式使用，默认 16。
- `nprobe`：IVF 每个 query 探测的簇数，仅 `ivf` 模式使用，默认 4。

输出中的 `average recall`、`average latency (us)`、`score/probe compute (ms)` 和 `topk/search compute (ms)` 是主要检查项。

本机 RTX 4060 Laptop GPU + CUDA 12.4 实测：

- `gemm 2000`：Recall@10 = `0.99990`，平均延迟 `58.43 us`。
- `ivf 2000 16 4`：Recall@10 = `0.96275`，平均延迟 `99.08 us`。
